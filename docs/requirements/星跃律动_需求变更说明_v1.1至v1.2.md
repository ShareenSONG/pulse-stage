# 《星跃律动》v1.2需求修改说明

日期：2026-10-20  
对比基线：v1.1《Mac浏览器可玩原型》  
新基线：[v1.2 · 双玩法与音乐挑战循环](./星跃律动_体感节奏游戏需求_v1.2_双玩法与核心循环.md)

本次只修改文档。当前可运行软件仍为v0.1.2；新玩法功能尚未据此开发。v1.0/v1.1保留，便于回溯。

## 1. 最大的变化：围绕一首音乐反复挑战

旧：原型入口→校准与动作配置→约60秒混合试玩→成绩/实验报告。

新：音乐大厅→选曲→Slash或Catch→难度与动作配置→简短准备→随完整音乐演奏→结算与个人纪录→练薄弱乐句/同曲重试/挑战更高难度。

动作实验室移为辅助入口；首局不需要先完成Z实验，双肩/双腕可靠即可开始XY。后续选择Z再进行相应校准。

## 3. 两种玩法的区别

| | Slash挥切 | Catch接拍 |
|---|---|---|
| 怎么读谱 | 音符沿透视方向接近固定击中面 | 目标固定，收缩环到中心 |
| 怎么命中 | 指定手到拍按箭头方向切过区域 | 指定手到拍从区域外进入目标 |
| 主要感受 | 预判、挥臂衔接、重拍释放 | 伸展、左右呼应、空间定位 |
| 共同扩展 | 双手、定点保持、侧移避障、可选Z | 双手、定点保持、侧移避障、可选Z |
| 成绩 | 独立谱面和纪录 | 独立谱面和纪录 |

两玩法单曲内不临时混切读谱。保持音符使用专属图示与教学，不要求保持时继续挥切。

## 4. Z没有取消，改为服务乐句

XY作为默认；Z0允许任意前后方向；Z1要求靠近/远离并允许不确定。建议主曲18/30/46/58秒安排4个特殊单位，前后留净空与回位；同一时点XY使用双手替代，各配置共同内容保持一致。

方向由真实输入估计，不能用目标方向反推“识别成功”。不做厘米测距、不把手向前伸当整体位移、不连续要求累积后退。Z1仍为实验，不能因文档调整宣称已达标。

## 5. 本轮规模与不变项

保留Mac优先、浏览器、单目RGB、裸手、本地推理、科技未来美术，以及已经修复的跨页面持续取帧。

相对v1.1，新增双玩法、第二难度、简单保持/避障和乐句练习，P0范围有所扩大。为了保持原型规模，仍只做一首主曲；标准Z组合、进阶、轨迹/转轮、完整领舞角色、多人、装扮、联网与安卓不纳入本轮P0。

当前模型仍为MediaPipe Pose Landmarker Lite（float16/1），SDK 0.10.32，CPU/WASM，33点、单人；本次不换模型。

## 6. 参考来源与名称更正

[Starri Steam官方页面](https://store.steampowered.com/app/1940410/Starri/)核对挥切/接拍、身体避障、手臂旋转和挑战反馈；[《节奏大师》腾讯App Store介绍](https://apps.apple.com/cn/app/节奏大师/id493901993)核对下落式读谱、敲击/滑动和人工谱面。主循环具体页面、百万制、阈值、练习等是本作设计，不声称为参考作品原规则。

用户已确认此前所说的《舞动奇迹》实际是《舞力全开》（Just Dance）。已同步更正需求第01、06、20节及版本索引，移除原有的名称确认占位说明。

参考[育碧官方介绍](https://news.ubisoft.com/en-gb/article/4PvGQbg9rxVwrRqaanBfv5)与[摄像头说明](https://www.ubisoft.com/en-us/news/ignt.55757/revolutionising-motion-gaming-the-camera-controller-feature)：本作借鉴领舞示范、下一动作图示、连贯舞句与整曲演出。P0以原创简化示意实现；完整领舞角色保持P1。新增约束：预告与谱面同源、左右/方向一致、不遮读谱，不让玩家同时承担相互冲突的模仿与音符任务。

评分继续按本作音符契约；“完整编舞相似度评分”未纳入当前P0，需另立算法与真人验收。此次更正不增加第三个主玩法、不换模型，也没有修改运行代码。
