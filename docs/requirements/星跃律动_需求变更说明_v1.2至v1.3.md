# 《星跃律动》v1.2→v1.3需求变更说明

日期：2026-10-20。新基线：[v1.3 · 上半身XY与一分钟可玩闭环](./星跃律动_体感节奏游戏需求_v1.3_上半身XY一分钟闭环.md)。参考拆解：[用户视频的可观察内容与取舍](./参考视频拆解_XY玩法依据.md)。

本次只更新需求与说明，运行软件仍为v0.1.2。v1.2原文保留作历史版本，冲突时以v1.3为准。

## 1. 总体变化

由“同时探索双玩法、多难度、Z与乐句练习”，收敛为“先把上半身XY输入、挥击判定与约一分钟连续游玩做扎实”。体验以用户本次提供的视频为主要依据，强调透视来谱、双手光迹、连续挥击、命中碎裂、Perfect/Combo和歌曲完成。

主循环：上半身准备→简短示范/4拍倒数→约64秒演奏→完成→结算→同曲重试。

## 3. 当前明确暂缓

Z0/Z1的玩家入口、校准、谱面与精度测试；独立Catch、定点保持、轨迹/转轮、强制避障/下蹲；标准/进阶多难度；完整领舞、慢速分乐句练习、多曲库/多人/联网与安卓。

这是本轮缩小范围，不是断言单目Z技术不可行。既有研究/代码/成绩可保留，但在后续v1.3实现中不能影响XY开局、判分或资格。旧软件当前仍可能显示这些入口，本次文档更新没有暗中改站点。

## 4. 为“精准”增加的可核验要求

- 单独检查双肩、双肘、双腕是否在框和可靠；不再以髋部不足解释手臂失败。
- 光标、真实坐标、碰撞目标共用映射，避免看着碰到了但判分位置不同。
- 快挥采用有效短轨迹穿越；失踪后跳变、预测点和重复消息不能计分。
- 左右手身份不按屏幕左右排序；交叉、遮挡、反向恢复加入回归。
- 同时测静止抖动与动态延迟，不能靠过度平滑显得稳定。
- 分开统计玩家动作不合格、模型误判与技术未观测；保护样本仍进入真实召回评估。
- 指标为目标而非承诺：关节可用率、手别、腕点误差、挥击精确率/召回等见需求第17节，必须有真人保留验证结果。

## 5. 一分钟内容更接近视频的方式

同一读谱界面连续演奏；暖金/青蓝双手尾迹对应真实动作，音符到拍命中后碎裂；用左右交替、上下变化和双手重拍连成短句，保留音乐高峰与收尾。

建议64秒曲使用80评分单位，68单手+12双手Pair，起承转合为4/20/20/28/8单位。这是待真人审核的编排方案，不是从视频抄出的谱面。若输入性能不能支撑，先优化输入或调整谱面并记录，不用动态放宽窗口或自动吸附掩盖。

视频约117秒，本作选约64秒是当前规模取舍；视频115秒处的SONG COMPLETE作为结束反馈参考。绿色门框/旋纹元素机制未确认，当前不要求玩家躲避、下蹲或转轮，避免给出没有明确识别契约的指令。
