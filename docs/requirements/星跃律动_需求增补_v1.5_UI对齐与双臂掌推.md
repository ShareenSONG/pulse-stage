# 星跃律动 · v1.5 需求增补

状态：按2026-10-21本轮测试反馈直接实施，对应软件v0.4.0。本文件覆盖v1.4中“不使用手臂评分”的限制，其余身体驾驶、音乐时钟、因果判定和本机隐私要求保留。当前只增加一种新操作，不扩展Z、挥击、跳跃或下蹲。

## 依据与目标

用户提供的本机测试录屏长约134秒、2932×1740。录屏可观察到身体驾驶、方块判定与完成提示，不能由录像直接推导人体精度或物理延迟。可见UI问题包括首页曲名与背景文字重叠、分数/连击分散、长期保留大量微小提示和技术标签。

本轮目标：明确主体、统一视觉基线、减少常驻文字；在原有肩膀驾驶之外，逐步引入左右掌推停留，让手臂动作有明确目标、进度与反馈。

## 视觉调整

- 首页只保留游戏主标题、一句玩法、曲目信息与开始入口，移除背景重复曲名、英文口号、PILOT等技术标签与版本/FPS页脚。
- 舞台全屏展示，曲名、连击、得分共用顶部网格与安全边距。连击移出跑道阅读区，底部保留时间进度、预览/设置；常驻操作说明、左右英文道名和驾驶位置条退出局内。
- 设置收进弹层，局内打开设置先暂停。输入状态仅在异常或辅助练习时出现。模型、六点置信度与FPS留在专用身体定位页。
- 主要说明字体15–20px；核心数字25–36px；掌推卡片标题20px、状态14px。键盘提示不与跑道目标重叠。维持既有科技舞台与原创几何素材。
- 固定命中线、HUD和未命中目标不受撞击震动影响；左掌用青绿、右掌用暖金，同时明确中文手别与手掌图形，不能只靠颜色理解。

## 唯一新增操作：举掌停留

玩家看到跑道上方对应侧的滑块，抬起指定手掌到肩部附近，手腕高于肘部，稳定停留约0.45秒。滑块从空逐渐充满；充满就完成操作，可以放下手，不要求一直举到音乐拍点。

这是一种操作的左右手对称版本，不引入第二种挥切或推拉动作。不需要向摄像头推进，不使用单目Z方向判断。

当前识别依据为对应侧的肩、肘、腕三点，配合双肩尺度归一化；不宣称验证了掌心朝向、手指展开或区分拳头。界面“掌推”表示抬掌停留的身体动作语义，不是精细手势分类。

初始举掌条件：肩肘腕均可靠、在画面内，手腕不低于肩约0.12个肩宽、至少高于肘约0.18个肩宽；横向位于自身对应侧的舒适范围，不要求高举过头。保持期间肩相对腕位置变化控制在约0.25肩宽内。参数是初始值，仍需真人验证。

## 时序与完成记忆

滑块在目标拍前2.8秒出现，从出现起即可操作。连续可靠观测积累0.45秒并有至少3个有效样本才完成；单次瞬时举手、用错手、摆动很大或中途放下均不能假造连续停留。

完成状态按目标ID锁存，存储完成生效时间和停留长度。锁存后放下手或该臂后续失去跟踪，不撤销已完成操作；音乐到拍才播放成功音、完成脉冲并计分，不提前清除后续目标。每目标只结算一次。

到拍后才收到的新姿态不能补写过去。没有完成且手臂可靠但未按要求操作，记Miss；因缺点、过期或采样断层无法确认，记输入保护。数据新鲜度和连续采样上限初始180ms；不能把丢点/冻结插值成举掌停留。

暂停时清空按键与过期输入。乐句恢复撤销回放区判分，也撤销该区掌推完成记忆，禁止带着已充满滑块重复得分。

## 双肩与手臂的职责

- 双肩继续负责飞行器连续左右驾驶，不改原映射、死区和碰撞宽度。
- 单侧手臂不可用仅影响该侧掌推，不暂停身体驾驶；持续双肩丢失仍按原规则暂停。
- 掌推使用独立的上方卡片充能/完成表现与较高音短音；不伪造跑道撞击，不把手腕变成第二个飞行器。
- 本轮不要求完成后放下重举才允许操作下一个同手滑块，也不把另一只手抬起设为否定条件。后续若设计更强节拍动作，另行调整规则。

## 64秒渐进编排

保留同一首120BPM原创音乐和60个身体节奏块，新增8个掌推目标，共68个评分单位。降低横移密度，给抬手留出居中段落；掌推拍点前至少1.5秒到拍后0.5秒的强制身体目标均在中道。

| 时间 | 内容 |
|---|---|
| 0–约11秒 | 先熟悉肩膀驾驶，没有掌推滑块 |
| 11.2–14秒 | 首次左掌预告与操作，14秒结算 |
| 19.2–22秒 | 首次右掌，22秒结算 |
| 30/38/46/54秒 | 左右交替巩固同一种操作 |
| 60/62秒 | 左右掌推收尾，不引入新动作 |

一次只出现一个掌推目标，不要求同时掌推两侧。首次左掌和右掌之间留8秒理解时间。

提供独立“练习掌推”：先左掌、再右掌，实时显示进度；练习不计入歌曲分数。键盘试玩沿用A/S/D驾驶，新增按住Q/E模拟左右掌；不读取谱面自动举掌。

## 评分、记录与验证

身体单位继续按音乐拍点位置误差分Perfect/Great/Good/Miss。掌推完成得Perfect，未完成或技术保护为0；总分仍按68单位百万归一化，Combo不乘分。结算显示掌推完成数/8、节奏完成度及等级分布；侧道成绩只统计身体单位。

新谱面`neon-bloom-palm / 1.5.0`，规则`body-palm-1.5.0`，沿用肩膀校准映射`shoulders-1.4.0`。旧v1.4谱面/成绩留存，不能直接横向比较或覆盖。报告记录每次判定、停留长度、保护原因与反馈时序，不保存连续视频或骨架。

验收重点：两个手别正确、同一人轻横移不改变举掌语义、短按/摆动/低置信度不误计、充满后可以放下、过期数据不充能、手臂异常不暂停驾驶、暂停回放不带入旧充能、68单位完整结算与重试、全屏/窄窗口无文字重叠。

自动测试及键盘流程不能替代真人举掌召回率、误报、取景舒适度和模型吞吐验收。当前模型仍为MediaPipe Pose Landmarker Lite、CPU/WASM、33点，未新增精细手部模型。当前验证证据与限制以项目VERIFICATION.md为准。
