## 2. 独立手部识别

人体使用 MediaPipe Pose Landmarker Lite，单人 33 点；新增 MediaPipe Hand Landmarker，最多双手、每手 21 点，SDK @mediapipe/tasks-vision 0.10.32。本地模型/WASM，无云端识别。

- 人体与手部使用独立 Worker，不积压帧；分别优先 GPU，初始化不支持时回退 CPU。手部 GPU 运行异常可重建为 CPU，不中断人体驾驶。首次手部推理允许最多15秒预热，之后2.5秒无结果触发兼容重试；启动游戏需两个模型已返回可用结果。
- 手部约15Hz独立采样，人体独立持续输出；实验室显示实际手部运行方式、帧率和推理耗时。性能不足仍按原辅助/保护规则处理，不宣称所有设备稳定30FPS。
- 通过手部腕点与人体左右腕点的几何距离作一对一关联，结合人体解剖左右，再镜像显示；不依赖手部检测数组顺序或 Handedness 标签直接决定操作手。两腕明显重叠时不猜测身份。
- 掌心为手腕及四个掌指根节点的均值，用掌心而非单个人体手腕点定位。
- 张开手掌、至少三根非拇指伸展且掌心抬到肩部附近，才激活光点。判断依据是二维关节几何，不声称识别真实前推深度、掌心法线或厘米位移。
- 肘点不再作为手掌的硬门槛；人体手腕仍需可关联。手太小、手指被裁切、双手重叠、关联失败或数据过期，显示具体原因，不拿旧位置持续计分。
- 位置用已定位的固定中线/肩宽归一化：x=(定位中线-掌心x)/定位肩宽/1.15。身体移动不再改变一个静止掌心的坐标原点。未定位的实验室临时参考当前肩中心；游戏必须先完成定位。
- 增加24ms时间常数的因果平滑，附近轨道0.10范围进入吸附、0.17范围离开；实际绘制与判定都使用同一有效位置。超180ms重获后重置平滑，不外推旧手掌。

## 4. 沿用的玩法

64秒、120BPM、60个下层身体块 + 8条上层滑块，共68评分单位。下层身体横移、空间等级、音乐拍点、节奏、谱面数据均不改。左道左掌、右道右掌、中道任一手；上层接住头部并保持至尾部，覆盖95%/85%/65%分Perfect/Great/Good。

双肩与手部组合证据按较旧采集时间计算新鲜度，有效时间使用结果到达时刻；不把后来识别的数据回填早先拍点。过180ms不计有效停留。暂停、回放清理、成绩资格及原有输入保护继续生效。新手掌映射版本进入纪录键，历史成绩保留。
